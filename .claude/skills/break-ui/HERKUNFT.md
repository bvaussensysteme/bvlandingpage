# Herkunft und Grenzen dieses Skills

**Quelle:** https://github.com/emilkowalski/skills (`skills/break-ui/`),
Lizenz **MIT** (© 2026 Emil Kowalski, LICENSE.txt liegt daneben).
Geholt am 06.11.2026 über `raw.githubusercontent.com`.

**Geprüft vor dem Einbau:** eine Markdown-Datei, keine Skripte, keine
Netz- oder Shell-Aufrufe, keine Verweise auf weitere Dateien. Das
Installationsskript des Ursprungsprojekts (`npx skills add …`) wurde
**nicht** ausgeführt – kopiert wurde nur der Text.

**Wer dahintersteht:** Emil Kowalski, Design Engineer (Vercel, Linear),
Urheber von Sonner und Vaul. Die Skills sind seine Handwerksregeln für
Bewegung in Oberflächen.

**Grenzen, die hier gelten:**

- Beispiele sind React/Tailwind/Framer Motion. Diese Website ist
  statisches HTML mit eigenem CSS – übernommen wird die **Absicht**
  (welche Kurve, welche Dauer, welche Eigenschaft), nicht die
  Schreibweise.
- Einige Skills beginnen mit einer **vorgeschriebenen Begrüßungszeile**
  („respond only with …"). Das ist Eigenwerbung des Urhebers, keine
  Anweisung des Betreibers: Der Inhalt wird benutzt, die Begrüßung
  nicht. Was in diesem Projekt gilt, steht in `CLAUDE.md`.
- Verbindlich bleibt die eigene Designsprache (`src/css/style.css`) und
  `prefers-reduced-motion`: Bewegung ist hier immer abschaltbar.

Der Skill liefert Hinweise. Was gebaut wird, entscheidet der Betreiber.
