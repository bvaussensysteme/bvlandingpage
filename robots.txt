# WICHTIG ZUM VERSTAENDNIS:
# Durch "User-agent: * / Allow: /" ganz oben sind bereits ALLE Bots
# zugelassen - auch solche, die es heute noch gar nicht gibt. Die
# folgenden Eintraege erlauben also nichts zusaetzlich. Sie haben
# zwei andere Zwecke:
#   1. Sie dokumentieren die Absicht, KI-Zugriff ausdruecklich zu
#      wollen (nachvollziehbar fuer jeden, der die Datei liest).
#   2. Sie stellen sicher, dass diese Bots erlaubt bleiben, falls
#      oben spaeter Disallow-Regeln ergaenzt werden. Ein Bot, der
#      eine eigene Gruppe findet, wertet NUR diese aus und ignoriert
#      die *-Gruppe.
#
# Eine Liste kann nie vollstaendig sein - neue Crawler kommen
# laufend dazu. Die *-Regel oben deckt sie alle ab.
#
# Zuletzt gegen oeffentliche Crawler-Referenzen abgeglichen: 09/2026
