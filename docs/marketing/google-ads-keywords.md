## Standort-Ausrichtung (statt Geo-Negative)
- Kampagnen-Einstellungen → Standorte → **Radius 60 km um Dernbach** (bzw. gezielt Koblenz, Neuwied, Montabaur, Limburg, Westerwaldkreis).
- Standortoption: **„Anwesenheit: Personen in diesem Gebiet"** (nicht „Interesse an"), sonst zahlt man für Auswärtige/Urlauber.

## Budget & Gebote (Start)
- **Budget:** 10–15 €/Tag zum Start. Klein anfangen, Daten sammeln, dann erhöhen.
- **Gebotsstrategie:** Start mit **„Klicks maximieren" + manuellem CPC-Limit** (~1,50 €). Nach ~15–20 Conversions auf **„Conversions maximieren"** wechseln.
- **Voraussetzung:** Conversion-Tracking (Anrufe + Formular-Absendungen) muss eingerichtet sein.
